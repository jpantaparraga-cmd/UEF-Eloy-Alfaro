Proyecto

Unidad Educativa Fiscal “Eloy Alfaro”

El proyecto consiste en crear una página web institucional destinada a la difusión de noticias y avisos escolares.

La propuesta utiliza una interfaz intuitiva, accesible y adaptable a diferentes dispositivos mediante diseño responsivo.

Tecnologías

HTML5

Estructura y organización semántica.

CSS3

Apariencia, distribución y adaptación responsiva.

JavaScript

Interactividad y comportamiento dinámico.

Bootstrap

Framework de apoyo para componentes y diseño responsivo.

Características

  • ✓ Diseño adaptable
  • ✓ Navegación clara
  • ✓ Etiquetas semánticas
  • ✓ Archivos organizados
  • ✓ Noticias, avisos, eventos y contacto
