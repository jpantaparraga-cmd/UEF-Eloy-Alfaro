VERSIÓN CORREGIDA - U.E.F. ELOY ALFARO

Esta versión NO depende de Internet para la navegación ni para los estilos.
Bootstrap fue reemplazado por un archivo local compatible con los componentes usados.

ABRIR:
1. Descomprime el ZIP completo.
2. Entra a la carpeta.
3. Abre index.html.
4. Usa el menú: Inicio, Noticias, Avisos, Eventos, Institución y Contacto.

IMPORTANTE:
- Mantén toda la estructura de carpetas.
- No abras solamente un archivo HTML copiándolo fuera de la carpeta.
- Las imágenes están en img/.
- Los estilos están en css/ y lib/.
- JavaScript está en js/app.js.
- El formulario de contacto es demostrativo y no envía correos reales.
